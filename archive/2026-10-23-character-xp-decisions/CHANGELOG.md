# SYS-03 XP·초기 레벨 결정 반영 전 보존

문서6개를 수정 전 바이트 그대로 보존했다. 승인된 개인별 고정 전투 XP·비참가/다른 파티 제외·모든 시스템의 XP 제공·부활 외 아이템 사용 제한·Lv100·상한 이후 XP 누적 저장·캐릭터별 지정 초기 레벨/재합류 유지를 현행 문서에 반영했다.

기존 상한50 제안·상한 초과 XP 폐기·제공 시스템 제한은 현행 기준에서 제거했다. 합류 기술 보정·전투 외 비아이템 XP의 HP0 처리와 수치/에셋 세부는 미정/제안으로 구분한다. 시험 곡선의 상한5는 경계 검사용이며 정식 상한100과 다르다.

원작·에셋 부록·기존 승인 기록·이동 목업은 수정하지 않았다. 승인 근거는 `qa/approvals/character-xp-decisions-2026-10-23.json`, 이번 문서 검사 결과는 `qa/character-xp-decisions/document-checks.json`을 따른다. 게임/브라우저 실행 검사는 수행하지 않았다.
