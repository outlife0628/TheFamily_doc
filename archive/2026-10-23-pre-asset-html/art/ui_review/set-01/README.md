# The Family — UI 에셋 1차 검수본

상태: **사용자 검수 대기 / 목업 미적용**.

[승인된 단순화 시안](../../../reference/art/approved_direction/simplified_movement_concept.png)을 입력 참고로 사용해 내장 `image_gen`으로 개별 PNG를 생성했다. 시안의 픽셀을 무손실로 잘라낸 원본은 아니며, 형태와 재질을 재구성한 검수본이다. 전체 화면·새 배치·문구·지명·수치를 생성한 결과물이 아니다.

문자·숫자는 전부 비워 두었다. 미니맵 안의 지도·표식도 포함하지 않는다. 나침반은 선택한 형태에 대해 가장자리 색 번짐을 추가 정리해야 하며, 두 안 모두 배포용 확정본이 아니다.

## 01·02 버튼

같은 자리에서 사용할 부품으로 윤곽을 맞췄다. 금색의 밝기, 안쪽 면의 깊이, 테두리 두께, 꺾인 모양을 시안과 비교한다. 아직 실제 버튼 크기에서의 글자·포커스·사용 불가·누름 상태를 검수한 것이 아니다.

## 검수 후 진행

먼저 부품별 수정·승인 의견을 받는다. 선택한 형태와 재질을 기준으로 필요한 상태별 변형·정확한 배포 크기·투명 여백·9-slice 경계를 정리한다. 승인 전 HTML/CSS/JavaScript 변경이나 목업 재작업을 진행하지 않는다.

파일 검사 결과는 [VALIDATION.md](VALIDATION.md), 입력한 프롬프트는 [PROMPTS.json](PROMPTS.json)에 보관했다. PNG는 원본 생성 파일의 알파를 바이트 그대로 보존해 복사했다.
