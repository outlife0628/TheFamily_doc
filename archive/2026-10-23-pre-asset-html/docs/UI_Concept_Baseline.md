# The Family — 현행 UI 콘셉트 기준

상태: H-2 / M-1 / D-1 / B-1 구조 유지, SYS-02 아트 적용 기준.

## H-2

좌상단 지역명, 우상단 소형 미니맵, 미니맵 아래 추적 목표 하나, 대상 근처 한 행동 표식, 하단 왼쪽 상황 안내, 하단 오른쪽 작은 입력 안내를 사용한다. 평상시 전원 초상·HP·레벨·지갑·달력을 상시 노출하지 않는다. 대표와 추종 인물의 현장 표시 수는 파티 정원을 바꾸지 않는다.

## M-1과 지도

목록·상세·비교와 하단 고정 행동 영역을 공용화한다. 월드맵은 지도 면+목적지 목록+여행 계획+고정 행동 영역을 조합한다. 지도 표식과 목록 선택은 같은 상태다. 목적지 선택을 중복 승인하는 별도 버튼을 두지 않는다. 현재 위치와 선택 목적지는 서로 다른 기호·문구로 구분한다.

## 확인창

기간·비용·잔금·수단·적재·인원을 같은 공용 상세 규격으로 표시한다. 취소/확정 버튼은 모달 하단에 고정하며 취소에 초기 포커스를 둔다. 확인창을 열거나 취소하는 것만으로 비용·시간·실제 위치는 변하지 않는다.

## 유지되는 다른 화면군

D-1은 작은 양측 일러스트·현재 화자·단일 대사, B-1은 최대 8인 하단 2열×4행 상태·고정 명령 영역이다. 이번 이동 목업에서 이 화면군과 관련 시스템을 새로 구현하지 않는다.

## 자료 경계

단순화 보드는 재질·색·버튼 인상의 기준이다. 보드 속 좌상단 미니맵·목표 3개·상시 초상·임의 지명·레벨·수치는 채택하지 않는다. 확장 이미지 4장은 참고용 정적 이미지다. 월드맵은 사용자 원본을 비율 유지해 사용한다. 본작은 시드리아와 크리스·브람 하르트·엘리아나 베일·올리버 크로포드를 기준으로 하고, 3D 공간+2D 픽셀 캐릭터 표현을 유지한다.
