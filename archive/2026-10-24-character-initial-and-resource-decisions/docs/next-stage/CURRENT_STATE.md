# The Family — 현재 승인 상태와 다음 작업

상태: SYS-02 이동 HTML 승인 / SYS-03 캐릭터 디자인의 남은 정책을 하나씩 확인 중. 캐릭터 스탯/성장·HP/SP와 실제 스프라이트/아이콘/애니메이션 파일 관리를 이번 디자인에 함께 포함한다.

## 승인된 기준

승인 대상은 [이동 HTML 실행본](../../prototype/movement-assets-v2/index.html)의 UI 에셋과 검토 동선이다. 필드 HUD, 원본 월드맵의 목적지 선택, 출발 확인, 여정/정차/현장 확인/재개/도착, 공용 창·목록·상세·확인·행동 부품을 다음 UI 작업의 기준으로 사용한다.

1920×1080·글씨100% 단일, 제목/본문 계층, 우상단 미니맵·목표 하나, 주 행동 하단 오른쪽·취소 바로 왼쪽·보조 하단 왼쪽을 유지한다. 같은 공용 행동 버튼은320×64px·간격16px다. 승인 아트를 처음부터 다시 승인받는 절차를 추가하지 않는다. 추가 인물 이미지나 새 부품이 필요한 경우에만 해당 추가분을 검토한다.

승인 실행본33개 파일의 SHA-256은 [승인 목록](../../qa/approvals/movement-assets-v2-2026-10-23.json)에 보존했다. 기존 목업 파일을 변경하지 않았다.

성장A·6기본 스탯의 종류/역할·HP+SP·전투 후 현재량 보존·레벨업 새 최대치 전량 회복을 승인 기준으로 한다. HP0은 승리 XP 제외/부활 후 활동이며 부활 아이템 이외 모든 아이템 사용이 불가하다.

전투 XP는 참가하고 승리 시 활동 가능한 주요 인물에게 고정량을 각각 지급하고 제외 몫을 재분배하지 않는다. 대기·비참가·다른 파티는 해당 전투 보상을 받지 않는다. XP는 모든 시스템이 명시된 효과로 제공할 수 있는 공통 변수다. 레벨 상한100·MAX 이후 XP 누적 저장·파티 평균과 관계없는 캐릭터별 지정 초기 레벨/재합류 유지도 승인 기준이다. [추가 승인 기록](../../qa/approvals/character-xp-decisions-2026-10-23.json)을 보존했다.

전투 외 비아이템 XP의 HP0 처리·합류 기술 보정·곡선/계수·부활량/가격·에셋 관리 세부를 순차 검토한다. 승인 항목을 다시 질문하지 않는다.

## 기술 검수 상태

| 항목 | 확인 상태 |
|---|---|
| 사용자 승인 | 이동 HTML 작업 승인 및 다음 단계 준비 지시 수령 |
| 브라우저 열기 | 앞선 실행에서 HTTP200·승인 에셋 CSS 참조·Chrome의 해당 페이지 창 제목 확인 |
| 단위/회귀23개·구문12개·HTTP28개 | [이전 실제 실행 기록](../../qa/movement-assets-v2/REPORT.md)에서 통과 확인. 이번 준비 작업에서 재실행하지 않음 |
| 자동 브라우저 동선·포커스·IME·시각 검사 | 이전 자동 실행 실패 기록 유지. 사용자 승인으로 검사 통과를 소급 기록하지 않음 |
| 실제 화면 캡처 | 확보0장. 정적 생성 이미지로 대체하지 않음 |
| Godot·Hera·Map Tool | 미연동/미검증 |
| 정식 게임 수치 | 도시 UV·노선·기간·운임·적재·간이 스프라이트는 시험 데이터 유지 |

사용자 승인과 기술 검수 결과를 분리한다. 남은 도구/엔진 검수는 다음 기획 준비를 막는 재승인 절차로 사용하지 않으며, 실제 연동/통합 전 해결할 항목으로 유지한다.

## 다음 작업 경계

현재 순서는 [기존 단계 구성](../../reference/design_snapshot/00_Planning_Map_Ver0.6.md)의 SYS-03 캐릭터 시스템·UI다. [캐릭터 디자인](../character/03_Character_System_UI.md)에서 인물/스탯·산출/보정·개인 레벨/XP·성장/기술·HP/SP 소비/회복·HP0·저장·관련 UI/예외를 한 설계 범위로 검토한다. 위승인규칙을유지하고나머지수치/정책을검토한다. [에셋관리부록](../character/Character_Asset_Tables.md)의파일/리비전·영역·외형/용도·방향/프레임·로딩/해제는검토안이다.4/8방향/원화크기는미정이며관계/평판·적별XP·최종전투식·일반회복품/휴식조건은연결협의사항이다.

현재 검토 요청은 [보강 범위·선택표](../character/Character_Review_Request.md)를 따른다. [준비 문서](SYS03_Preparation.md)는 유지 기준과 작업 순서를 안내한다. 이번 산출물은 문서/합성 메타데이터이며 실제 이미지 제작·HTML·Godot 구현은 미착수다. 수정 전 문서6개는 별도 아카이브로 보존했다. 원작·승인 이동 실행본은 변경하지 않았다.
