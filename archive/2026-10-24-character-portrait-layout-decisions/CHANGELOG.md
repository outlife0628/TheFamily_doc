# SYS-03 초상 영역·아이콘·기본 외형 결정 반영 전 보존

수정 전 현행 문서6개를 바이트 그대로 보존했다. 목록 얼굴 아이콘은 전용 초상의 지정 얼굴 영역을 재사용하며 장비 교체 시 필드 스프라이트/초상의 기본 외형을 유지한다. 초상 구도는 아트 디자이너가 결정하고 UI 표시 영역만1920×1080 기준320×400px로 정의한다.

UI 표시 영역과 원본 파일/자르기 좌표를 분리했다. 합성 메타데이터 예제의 얼굴 아이콘도 초상과 같은 파일/리비전을 참조하도록 갱신했다. 원본 그림의 크기·흉상/반신/전신 구도는 확정하지 않았다. 실제 이미지 생성/편집·새 HTML·Godot 구현은 수행하지 않았다.

원작·수치/자원 테이블·기존 승인 기록·이동 목업은 변경하지 않았다. 승인 기록은 `qa/approvals/character-portrait-layout-decisions-2026-10-24.json`, 문서 검사 결과는 `qa/character-portrait-layout-decisions/document-checks.json`이다.
