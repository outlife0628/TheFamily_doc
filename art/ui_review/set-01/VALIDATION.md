# UI 에셋 파일·시각 확인

상태: 기본 파일 확인 완료 / 사용자 아트 검수 대기 / HTML 미적용.

## 실제 수행한 확인

- 내장 `image_gen`으로 8종 및 나침반 비교안 1개를 생성하고 각 결과를 직접 확인했다.
- PNG 9개를 프로젝트의 이 폴더에 복사했다. 원본 생성 파일은 남겨 두었고 기존 파일은 덮어쓰지 않았다.
- Node 기본 모듈로 PNG를 직접 읽어 9개 모두 8bit RGBA, 알파 최솟값 0·최댓값 255, 실제 투명 픽셀 존재를 확인했다.
- 미니맵 중앙 알파는 0이다. 지도와 표식을 그려 넣지 않고 테두리만 분리했다.
- 코드·텍스트로 부품을 대체하지 않았고, 문구·숫자를 에셋에 넣지 않았다.
- 목업 파일 14개의 작업 전후 해시를 대조했다. 결과는 `prototype-preservation-result.json`에 기록한다.

검사 실행: `node art/ui_review/set-01/inspect-assets.mjs`. 픽셀을 수정하지 않는 읽기 전용 검사다. 세부 크기·해시·알파·내용 경계는 `asset-inspection.json`을 따른다. 생성 파일 복사의 바이트 일치는 `generation-copy-check.json`을 따른다.

## 남은 품질 항목

- 나침반에는 저알파 가장자리의 색 번짐이 남아 있다. 알파 128 이상에서 포화 적색 기준에 해당한 픽셀은 A 107개, B 2개다. 이 수치는 자동 검출 보조 정보이며 시각 합격을 뜻하지 않는다.
- 나침반 A/B의 형태 선택과 함께 경계 정리가 필요하다. 정리 시도만으로 해결했다고 기록하지 않는다.
- 투명 여백·실제 배포 크기·축소 선명도·9-slice·상태별 변형은 확정/검수하지 않았다.
- 부품의 시안 일치와 최종 아트 만족은 사용자 검수 대상이다. 모든 에셋의 승인 상태는 대기다.
- HTML/CSS/JavaScript 적용·통합 실행·게임 엔진 검수는 수행하지 않았다.

중앙 바탕은 대부분 거의 불투명한 알파 253이며, 바깥 여백은 투명 픽셀을 포함한다. 후속 전달 과정에서 RGB로 평탄화하거나 알파를 버리지 않는다.
