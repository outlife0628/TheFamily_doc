# 이동 HTML 목업 인수 기준

**상태: 앞으로 실행할 검수 명세. 전부 미실행.** 이번 인수인계 패키지에는 새로운 HTML을 만들지 않았다.

## 구현 산출물의 권고 구조

```text
prototype/movement/
  index.html
  styles.css
  app.js
  data/review_data.json
  assets/
  README.md
  tests/
qa/movement/
  screenshots/
  REPORT.md
```

폴더 구조는 제안이다. 기존 로컬 프로젝트가 있으면 보호 범위를 확인하고 적합한 새 하위 폴더를 정한다. 프레임워크·패키지·브라우저 테스트 도구 설치는 실제 환경을 읽은 뒤 필요성을 설명한다.

## 최소 화면과 행동

| 화면 | 실제 동작 |
|---|---|
| 필드 HUD | 승인된 위치/목표/미니맵/상호작용 안내, 월드맵 열기/복귀. 현장 이동을 시연하면 검토용이라고 표시 |
| 월드맵 | 제공 지도 위 현재 도시·선택 목적지·공개 노선, 표식/목록 선택 동기화, 조건 요약 |
| 출발 확인 | 기간·비용·잔금·수단·화물 확인, 안전한 취소, 유효성 재검사 후 확정 |
| 여정 | 실제 이동 상태·남은 구간, 명시적 시간 진행, 정차·현장 확인·재개·도착 |

선택은 실제 이동이 아니며 출발/도착 시 비용·위치 결과를 한 번만 반영한다. 도착 자동 매매·자동 귀환은 없다. 모달과 화면 이동은 취소/선택/포커스를 보존한다.
