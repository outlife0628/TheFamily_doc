# SYS-02 — 이동 시스템·UI 현행 목업 명세

상태: 채택한 접근의 HTML 조작 검토. SYS-02 최종 승인·게임 통합 승인과 구분.

## 범위

필드 HUD, 제공 월드맵의 목적지·수단 선택, 출발 확인, 명시적 여정 진행, 정차·현장 확인·재개·도착을 한 파티의 시험 데이터로 구현한다. 차량 구매/개조·전투·거래·성장·다중 파티 경제·채무 엔딩은 구현하지 않는다.

## 동선과 상태

필드 → 월드맵 → 표식/목록 선택 → 노선·수단·기간·비용·적재 확인 → 출발 준비 → 취소/출발 확정 → 여정 진행 → 정차 → 현장 확인 → 여정 복귀·재개 → 도착 → 현지 필드.

선택 상태와 실제 위치를 분리한다. 조회·선택·확인창 취소는 현금·경과일·실제 위치·화물을 바꾸지 않는다. 출발 확정은 조건을 다시 검사해 단일 여정을 만들고 시험 운임을 한 번 차감한다. 출발 자체는 날짜를 진행하지 않는다. 명시적 진행은 다음 정차 또는 도착 경계에서 멈춘다. 도착은 한 번 위치를 바꾸고 화물을 보존한다. 자동 판매·자동 귀환·별도 보상은 없다.

이동 중에는 출발/목적 도시의 현장에 있는 것으로 표시하지 않는다. 실제 정차 지점에서만 현장 확인이 가능하다. 현장 확인은 정차 사건의 게임상 완료·전투 판정이 아닌 UI 검토 동선이다. 견적·불가 사유·취소와 복귀 문맥을 공용 부품으로 표시한다.

## 데이터와 실행

`prototype/movement/data/review_data.json`에 도시 표시 좌표·공개 노선·운임·기간·보유 수단·화물·파티 인물을 둔다. 좌표는 원본 지도상의 정규화 UV이며 Godot 월드 좌표가 아니다. 시드리아 이외 도시명은 종족/시설 분류를 사용한 시험 이름이다. 정식 지명·지리·경제 승인값으로 등록하지 않는다. 시작 날짜는 E.C.5000 기준 경과일로만 표시하며 미정 시작 월일을 만들지 않는다.

월드맵은 `reference/world/world_map_source.png`와 동일한 PNG 사본을 사용한다. 원본 1511×1041 비율을 유지하고 표식·노선·라벨을 분리한다. 확대·패닝은 표시만 바꾸고 실제 상태를 바꾸지 않는다.

필드는 자체 Canvas 간이 공간과 픽셀 스프라이트를 사용하는 시연이다. Map Tool 출력·Godot 씬·3D 물리·저장·Hera 연결은 미구현/미검증이다. 지도와 목업 상태는 브라우저 메모리에만 유지한다. 새로고침은 시험 초기 상태로 돌아간다.

## 입력·검수

현장 WASD/방향키 이동, Shift 걷기, E/Enter 상호작용, M 월드맵, J 여정, Esc 이전. 목록 방향키·Tab/Shift+Tab·Enter/Space, 지도 확대/축소·드래그를 지원한다. 모달 내부 포커스와 취소 복귀, 한글 조합/키 반복, 중복 실행을 검사한다. 실제 게임패드와 입력 재지정은 미검수다.

인수 기준은 최상위 인수인계의 `docs/Movement_HTML_Acceptance.md`에 있는 HTML-01, ART-01~03, UI-01~05, MOV-01~05, QA-01, GATE-01을 따른다. 현재 수행 결과는 `qa/movement/REPORT.md`만을 근거로 한다. 사용자 검토 후까지 SYS-03으로 진행하지 않는다.
