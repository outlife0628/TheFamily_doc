# 콘텐츠별 기획·UI 진행 구조

**현재 검토 단위: SYS-02 이동 시스템·UI.** 아래 기능을 한 번에 구현하라는 요청이 아니다.

| 순서 | 시스템·필요 UI | 상태 |
|---|---|---|
| 01 | 기본 시스템: 개요·표현·게임 흐름·각 화면 역할 | 큰 기준 승인. 최신 UI 정책에 맞는 문서 참조 정리는 필요 |
| 02 | 이동: 마을/실내/야외/던전/월드맵·여정·수단 | 현재 범위. 새 아트의 실행 HTML 미제작 |
| 03 | 캐릭터: 변수·성장·평판·능력 | 상세 검토 다음 순서 |
| 04 | 아이템: 사용품·장비·소유·제작·상점 | 다음 단계 |
| 05 | 전투: 인카운터·ATB·명령·결과 | 큰 규칙 유지, 상세 검토 별도 |
| 06 | 파티: 공통 8개×8명 편성·활동 | 큰 규칙 유지, 상세 검토 별도 |
| 07 | 용병: 고용·리더·계약·편성 | 큰 규칙 유지, 상세 검토 별도 |
| 08 | 교역: 현지 거래·흥정·화물·손익 | 큰 규칙 유지, 상세 검토 별도 |
| 09 | 이벤트: 연출·분기·기획자 작성 | 후속 상세 대상 |
| 10 | 퀘스트: 종류·단계·판정·보상 | 후속 상세 대상 |

추가 제안은 시간·일정, 사업·직원, 자금·계약·채무, 회복·휴식·주거, 조사·증거·협력, 저장·진행·설정, 공통 콘텐츠 제작 도구다. 독립 문서 분리와 실제 순서는 사용자 검토 전 확정하지 않는다.

각 기능은 **행동 → 조건 → 판정 → 상태 변화 → UI 정보/입력 → 취소/실패 → 저장/복귀 → 검수**를 같은 문서에서 다룬다. 후속 시스템의 미정 정책은 선행 가정으로 숨겨 구현하지 않는다.
