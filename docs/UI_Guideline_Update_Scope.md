# UI 지침 정합성 정리 범위

**상태:** Codex 착수 전에 읽을 항목. 이전 지침 파일을 이미 수정했다고 주장하는 문서가 아니다.

## 반영할 명시 결정

| 항목 | 적용할 현재 기준 | 필요한 문서 작업 |
|---|---|---|
| 글씨 프로필 | 100%만 지원 | 125/150% 선택·전용 레이아웃·기존 확대 QA를 현행 기준에서 제거 |
| 아트 원본 | 단순화한 컨셉 보드 | 종이/짙은 면/얇은 황동 포인트를 기준으로 공용 토큰 재정의 |
| 장식 정도 | 사용자가 과한 장식의 축소를 요청 | 모서리·구분선·작은 아이콘 중심, 대형 톱니·빛 번짐 반복 제한 |
| 기존 목업 | 아트 기준에서 제외 | 최신 배포 경로에서 제외, 사용자가 보존한 파일을 임의 삭제하지 않음 |
| 작업 게이트 | 시안 승인 후 HTML, 매 단계 검수 | 생성 이미지/실행 HTML/게임 구현 상태를 분리 |

## 구현 전에 알려야 할 충돌

1. 기존 지침은 남청 단순 면과 황동 장식 억제를 규정한다. 현재는 사용자가 요청한 종이·갈색/남청·앤티크 골드 재질을 반영하는 **시각 규정 갱신이 필요**하다. 과한 장식 축소 원칙은 계속 유효하다.
2. 기존 H-2는 우상단 미니맵·추적 목표 하나·전원 초상/HP 비상시 표시다. 생성 보드에는 좌상단 미니맵·목표 셋·4명 초상과 레벨이 있다. 사용자는 구조가 아닌 아트웍을 교체한다고 했으므로 **아트 방향 승인만으로 이를 새 구조로 채택하지 않는다**. 원래 구조에 새 재질을 적용하는 것을 기본으로 설명하고, 구조 변경이 필요한 경우에만 사용자 결정을 요청한다.
3. 보드의 세로 이중 행동 버튼과 화면별 다른 버튼 모양은 공용 고정 행동 슬롯에 맞춘 구현 명세가 필요하다. 위치 규칙을 버리는 것으로 해석하지 않는다.
4. 아르카디움·클라라 성도·스팀벨 거리·임의 인물/레벨·3D 캐릭터 등은 생성 이미지의 내용이다. 실제 본작은 시드리아, 크리스·브람·엘리아나·올리버, 3D 맵의 2D 픽셀 캐릭터다. 잘못된 문구/캐릭터를 그대로 콘텐츠로 만들지 않는다.
5. 보드의 재구성 지도 대신 `reference/world/world_map_source.png`를 월드맵의 지리 구성안으로 사용한다. 도시 좌표·연결 경로·소요일은 승인된 정식 지리가 없으므로 시험값으로 표시한다.
6. 고아원 채무 완납/기한 해제 등 중요한 규칙을 이동 UI 작업 중 재설계하지 않는다.

## 갱신 절차

인수인계 점검에서 위 항목과 파일 변경 계획을 먼저 보고한다. 사용자가 지침 반영·실행을 지시하면 현재 UI 지침과 SYS-02의 UI 절을 같은 기준으로 갱신하고 이전 문서를 별도 아카이브에 둔다. 본문에는 변경 연표를 남기지 않는다. 새로운 구조 변경이 없다면 이미 승인한 단순화 아트를 다시 승인받는 절차를 불필요하게 만들지 않는다.

최종 색·폰트·버튼 px는 승인 시안에 맞춰 구현에서 제안·검수할 값이다. 기존 목업의 248×64px 등을 새 아트의 확정값이라고 자동 재사용하지 않는다.
