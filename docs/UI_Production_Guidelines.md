# The Family — UI 제작 지침

상태: 승인된 정책을 반영한 SYS-02 제작 기준. 최종 아트·치수는 사용자 검토 대상.

## 화면과 글씨

- 기준 화면은 1920×1080, 게임 내 글씨 프로필은 100% 하나다. 확대 프로필 선택·전용 탭·전용 배치를 제공하지 않는다.
- 제목·본문·설명·숫자의 계층을 유지한다. 목업 시작 토큰은 제목 38px, 소제목 30px, 본문 26px, 보조 22px, 메타/짧은 키 안내 18px다. 구현 검토값이며 정식 배포 규격은 아니다.
- 작은 브라우저에서는 기준 화면 전체를 맞춰 표시한다. 이는 별도 글씨 프로필이 아니다. 브라우저·OS 확대를 차단하지 않는다.
- 긴 한글·금액·사용 불가 사유를 실제 출력으로 확인한다. 중요한 값은 말줄임으로 숨기지 않는다.

## 아트

`reference/art/approved_direction/simplified_movement_concept.png`의 단순화 방향을 사용한다. 밝은 종이 상세 면, 짙은 갈색·남청 표면, 아이보리 문자, 절제한 앤티크 골드 선택 강조가 공통 언어다. 종이 결·얇은 경계·작은 나침반/운송 아이콘을 사용하며 대형 톱니·상시 로고·두꺼운 다층 금속 프레임·반복 발광은 사용하지 않는다.

목업 색 토큰: 잉크 `#18252b`, 짙은 면 `#182226`, 종이 `#eee3cd`, 밝은 문자 `#f2eadb`, 금색 `#c6a36b`, 선택 청색 `#3f7682`. 배경과 합성한 실제 대비·아트 만족 여부는 검수 대상이다. 문자 알파를 면과 함께 낮추지 않는다. 선택·불가·위험은 도형·문구도 병행한다.

글자·수치·선택·버튼은 실제 HTML, 지도 표식·노선은 실제 SVG/HTML로 만든다. 전체 생성 이미지를 클릭용 화면으로 사용하지 않는다. 월드맵 배경만 사용자 원본 PNG를 그대로 사용한다.

## 공용 부품과 입력

`WindowSurface`, `ContextHeader`, `SelectableList`, `DetailPane`, `ConfirmDialog`, `ActionDock`, `ActionButton`, `InputHint`를 재사용한다. 같은 템플릿의 버튼은 공통 토큰을 사용한다. 목업은 224×64px, 간격 16px를 시작값으로 사용하고 실제 캡처로 검수한다.

- 주 행동: 하단 오른쪽. 취소/이전: 바로 왼쪽. 보조/도움말: 하단 왼쪽.
- 일반 화면은 화면 경계, 모달은 자신의 경계를 기준으로 고정한다. 본문만 스크롤하고 행동 영역은 고정한다.
- 선택·호버·견적은 실행이 아니다. 비용 있는 실행은 최종 확인 시 다시 검사한다.
- 모달은 한 깊이, 초기 포커스는 취소. 배경 입력 차단, 내부 포커스 순환, 닫은 뒤 이전 항목·스크롤·포커스 복원.
- 눌린 키 반복과 한글 조합 Enter가 새 화면 실행으로 이어지지 않게 한다.
- 불가·처리 중·선택·포커스를 구분하고 불가 사유를 화면 본문에서 읽게 한다.

## 제작·검수

승인된 단순화 아트 방향 → 실제 연결 HTML → 코드/브라우저/시각/지침 검수 → 사용자 검수 순서다. 승인된 아트 방향을 다시 처음부터 승인받지 않는다. 새로운 구조·게임 규칙 변경은 별도 검토한다. 브라우저·실제 캡처·Godot/Map Tool·사용자 만족 판단을 구분한다.
