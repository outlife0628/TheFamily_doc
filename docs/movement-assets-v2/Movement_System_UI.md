# SYS-02 — 승인 에셋 적용 이동 UI

상태: 이동 동선의 실제 HTML/CSS/JavaScript 검토 목업. SYS-02 전체 최종 승인·Godot 구현 완료본은 아니다.

## 조작 흐름과 상태

필드 HUD → 제공 월드맵에서 목적지 표식/목록 선택 → 공개 노선·기간·운임·수단·화물 확인 → 출발 준비 → 취소 또는 최종 출발 확정 → 여정 → 명시적 1일 진행 → 정차 → 현장 확인 → 여정 복귀·재개 → 도착 → 현지 필드.

선택한 목적지와 실제 위치를 분리한다. 조회·선택·취소는 자금·날짜·화물을 바꾸지 않는다. 출발 확정 시 보유·경로·적재·인원·자금을 재검사하고 운임을 한 번 차감한다. 출발 자체는 날짜를 진행하지 않는다. 시간 진행은 정차/도착 경계에서 멈추며 정차 현장 확인과 재개는 남은 여정·화물·지급 운임을 보존한다. 도착은 실제 도시 위치만 한 번 반영한다. 자동 판매·귀환·보상 지급은 없다.

월드맵의 지명·표식·노선은 원본 PNG와 분리된 SVG/HTML이다. 원본 1511×1041 비율을 유지한다. 지도 확대·패닝은 표시만 바꾼다. 미니맵은 HUD 우상단에서 현장 위치를 따르는 시험 표시다. 지역 현장 좌표와 정차 현장 좌표를 구분해 복귀 위치를 보존한다.

## 데이터

`prototype/movement-assets-v2/data/review_data.json`의 지리 UV·노선·기간·운임·수송량·현장 배경·인물 스프라이트는 시험 데이터다. 정식 지명이 있는 시드리아를 사용하고 외부 시험 거점은 인간/드워프/엘프 도시·항만으로 표시한다. 시안의 다른 게임 명칭을 사용하지 않는다.

본작 인물 크리스·브람 하르트·엘리아나 베일·올리버 크로포드 4명을 시연한다. 파티당 8명, 전체 최대 8개 파티 기준을 유지하되 편성 시스템은 구현하지 않는다. 운송 수송량과 인원 정원을 혼동하지 않는다. E.C.5000부터 경과일만 표시하고 미정 시작 월일을 만들지 않는다.

시험 기준 동선은 시드리아→인간 도시, 마차, 3일, 운임120G, 1일차 정차, 화물18/40칸이다. 초기 자금2400G는 출발 확정 후2280G가 된다. 도보의 적재 초과·엘프 도시 통행 중단·비공정 미보유/수단 부적합을 표시한다. 실제 지리·운임·기간·경제 공식의 기획 승인이 아니다.

## 입력·기술 경계

필드 WASD/방향키, Shift 걷기, 근접 E/Enter, M 월드맵, J 여정, Esc 이전/취소를 사용한다. 목록 위/아래·Tab/Shift+Tab·Enter/Space, 지도 드래그·휠·확대/축소·Shift+방향키를 제공한다. 글씨 크기 옵션은 100% 하나다.

필드는 Canvas 간이 배경과 시험 픽셀 스프라이트이며 Godot 3D 출력이 아니다. 이동 상태는 브라우저 탭 메모리에만 유지된다. 새로고침은 초기 시험 상태로 돌아간다. Map Tool·Godot·Hera·게임 저장·실제 물리·게임패드·전투·거래·성장·다중 파티 운영은 미연동/미검증이다.

실행은 [목업 README](../../prototype/movement-assets-v2/README.md), 실제 검사 결과는 [검수 보고서](../../qa/movement-assets-v2/REPORT.md)를 따른다. 인수 기준은 [이동 HTML 인수 기준](../Movement_HTML_Acceptance.md)의 항목을 현재 상태에 대조한다. 사용자 검토 후까지 다음 시스템은 대기한다.
