# SYS-02 — 승인 에셋 적용 목업 현재 상태

상태: 에셋 및 HTML 작업 승인됨 / 실제 소스 작성·코드 검사 완료 / 브라우저 실행·시각 검수 차단 / 사용자 검토 대기.

| 항목 | 적용 상태 |
|---|---|
| 실행본 | `prototype/movement-assets-v2/index.html` |
| 아트 | 승인 PNG 8종 적용. B 가는 선 나침반 사용. 원본 픽셀 보존 |
| 범위 | 필드 HUD·시험 보행, 월드맵 목적지 선택, 출발 확인, 여정·정차·현장 확인·재개·도착 |
| 구조 | 우상단 미니맵·목표 하나·상시 전원 초상 없음, 목록/상세/확인/행동 공용 부품 |
| 화면 | 1920×1080, 글씨 프로필 100% 하나 |
| 실제 화면 캡처 | 0장. Chrome·Edge 렌더러 초기화 실패로 미확보 |
| 게임 연동 | Map Tool·Godot·Hera 미연동. 현장 배경·스프라이트는 시험 표현 |
| 승인 범위 | UI 에셋 및 이동 목업 제작 승인. SYS-02 최종·게임 통합 승인 아님 |
