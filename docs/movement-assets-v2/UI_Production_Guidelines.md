# UI 제작 지침 — 승인 에셋 적용 HTML

상태: SYS-02 검토 목업의 현재 제작 기준. 최종 화면 만족도·치수 검수는 사용자 검토 대상이다.

## 화면·글씨·구조

1920×1080을 기준으로 게임 내 글씨 크기는 100% 프로필 하나다. 제목 38px, 확인 제목 32px, 소제목 28~30px, 본문 22~26px, 행동 24px, 보조 16~20px의 계층을 사용한다. 작은 브라우저에서는 화면 전체를 비율에 맞춘다. 글씨 확대 프로필·전용 배치·125/150% 옵션을 만들지 않는다. 지도 배율은 지형 표시 배율이며 글씨 옵션이 아니다.

H-2 필드 HUD는 좌상단 지역, 우상단 미니맵, 추적 목표 하나를 유지한다. 생성 시안의 좌측 미니맵·목표 셋·상시 전원 초상/레벨은 구조로 채택하지 않는다. 목록과 상세, 최종 확인, 동일 역할의 행동 슬롯을 공용화한다. 게임에 없는 시안의 지명·인물·수치·기능을 복사하지 않는다.

## 승인 아트와 실제 적용

밝은 종이 상세 면, 짙은 갈색/남청 표면, 아이보리 문자, 얇은 앤티크 골드 프레임과 작은 나침반을 사용한다. 승인된 PNG가 실제 재질이다. 원본 PNG는 그대로 두고, 자체 포함 PNG를 가진 SVG의 뷰포트로 투명 여백을 표시에서 제외한다. 창·카드·버튼은 CSS 9분할로 모서리를 유지한다. 전체 화면 생성 이미지에 클릭 영역만 올리는 방식은 사용하지 않는다.

| 승인 PNG | 적용 부품 | 표시 방식 |
|---|---|---|
| 01 금색 버튼 | 선택/확정/진행 주 행동 | 공용 320×64px, 9분할 |
| 02 먹색 버튼 | 취소/이전/보조 행동, 비활성 주 행동 | 공용 320×64px, 9분할. 비활성은 색/커서/disabled·사유 병행 |
| 03 종이 패널 | 목적지 목록·상세, 여정 명세 | 9분할 종이 면·모서리 |
| 04 확인창 | 출발 확인·검토 안내 공용 창 | 1100px 창, 어두운 제목부·종이 본문 |
| 05 어두운 패널 | 기본 표면·지도 창·여정 창·필드 안내 | 9분할, 얇은 테두리 |
| 06 원형 프레임 | 우상단 동적 미니맵 | 300px 프레임과 내부 원형 지도, 표식 별도 |
| 07 목표 카드 | 추적 목표 하나·목적지 선택 행 | 9분할, 실제 텍스트 별도 |
| 08-B 가는 선 나침반 | 공용 제목·시드리아 표식 | 작은 PNG 아이콘 |

색 토큰은 짙은 면 `#191e20`, 종이 `#eee2c9`, 종이 글자 `#322c23`, 밝은 문자 `#f0e5d0`, 금색 `#d4b574`, 포커스 청색 `#8dc2cf`다. 호버·누름은 밝기, 비활성은 먹색·명시 사유, 포커스는 독립 외곽선으로 구분한다. 문자 알파는 패널에 따라 낮추지 않는다. 래스터 가장자리 잔여 색 번짐과 합성 후 대비는 실제 화면 검수 항목이다.

## 공용 부품·행동·입력

`components.js`의 `windowSurface`·`contextHeader`·`selectableList`·`detailPane`·`detailRow`·`confirmDialog`·`actionDock`·`button`을 공용으로 사용한다. 주 행동은 하단 오른쪽, 취소/이전은 바로 왼쪽, 보조/도움말은 하단 왼쪽이다. 일반 화면은 화면 경계, 모달은 자신의 경계를 기준으로 한다. 행동 버튼 320×64px, 두 행동 간격 16px를 공통 사용한다. 본문만 스크롤하고 행동 도크는 고정한다.

취소에 초기 포커스를 두고 모달 밖 입력을 차단한다. Tab/Shift+Tab은 모달 안을 순환하고 취소 시 원래 선택·스크롤·포커스를 복원한다. 한글 조합 Enter, 키 반복, 더블클릭의 중복 실행을 방어한다. 선택·조회는 돈·시간·실제 위치를 변경하지 않는다. 지명·노선·버튼·수치·불가 사유는 실제 DOM/SVG UI다.

## 검수 게이트

에셋 및 HTML 진행은 승인됐다. 실제 브라우저 실행·시각/입력·지침 검수, 사용자 최종 검토는 별개다. [검수 보고서](../../qa/movement-assets-v2/REPORT.md)에 실제 실행 결과만 기록한다. 생성 이미지·실행 캡처·Godot 검수를 혼동하지 않는다. 사용자 검토 전 SYS-03 이후에 착수하지 않는다.
