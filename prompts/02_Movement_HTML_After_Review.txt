앞서 보고한 지침 정리와 이동 UI HTML 구현 범위를 승인한다.
승인된 단순화 아트 방향에 따라 실제 조작 가능한 HTML/CSS/JavaScript 목업을 제작해.

- 먼저 기존 지침의 글씨 확대 정책과 새 아트 정책을 현재 지시에 맞게 갱신해.
- 기준 해상도 1920×1080, 게임 내 글씨 크기 옵션은 100% 하나다.
- 이전 아트 목업을 재활성화하지 말고, 구조/동선 규칙과 새 시안의 아트를 구분해.
- 시드리아와 본작 인물/파티 기준을 사용하고 시안의 다른 게임 명칭을 복사하지 마.
- 제공한 월드맵 원본을 사용하고 지명/노선/버튼/수치는 실제 UI 요소로 구현해.
- 필드 HUD, 월드맵 목적지 선택, 출발 확인, 여정/정차/재개/도착만 우선 구현해.
- 창/목록/상세/확인/행동 버튼을 공용 컴포넌트로 만들어.
- 문서 본문은 현재 규칙만, 이전 버전과 변경 기록은 별도 아카이브로 보존해.
- 목업의 시험 데이터와 Map Tool 미연동 상태를 명시해.
- 실행한 화면을 캡처하고, 실제 실행한 테스트만 통과로 보고해.
- 새 설치나 구조 변경이 필요하면 먼저 영향과 이유를 알려줘.
- 기존 파일 삭제/덮어쓰기, Git commit/push, Godot 구현 착수는 별도 승인 없이 하지 마.

완료 보고에는 실행 파일 경로/방법, 변경 문서, 실제 화면, 테스트와 미검증 항목,
UI 지침 대조 결과, 내가 확인할 사항을 포함해. 사용자 검수 후까지 다음 단계는 멈춰.
