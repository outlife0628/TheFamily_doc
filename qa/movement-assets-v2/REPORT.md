## 사용자 검토 동선

서버와 주소는 [실행 안내](../../prototype/movement-assets-v2/README.md)를 따른다. 필드에서 M → 인간 도시 → 마차 확인 → 출발 준비/취소 → 출발 확정 → 1일 진행 → 정차 현장 확인 → J → 재개 → 1일씩 진행 → 도착을 확인한다. 시험값은 자금2400→2280G, 경과0→3일, 화물18칸 보존이다.

우상단 원형 미니맵·목표 하나, 금색/먹색 버튼과 종이/어두운 면의 시안 재현, 긴 한글과 불가 사유, 원형 경계 표식, 종이 패널 스크롤, 공용 행동 위치를 검토한다. 실제 브라우저에서 정상이라 확인되기 전 완료 판정을 하지 않는다.

## 미검증 경계

Map Tool·Godot·Hera, 정식 지리/운임/기간/경제·저장·게임패드·실제3D 충돌/카메라·전투·거래·다중 파티 운영은 미연동/미검증이다. 필드·인물·여정 풍경은 간이 시험 표현이다. UI 래스터의 작은 알파 경계 색 번짐은 실제 배경에 합성해 검토해야 한다. SYS-03 이후는 착수하지 않는다.
