# SYS-02 이동 HTML 검수 보고서

검사일: 2026-10-22. 상태: 코드·HTTP·원본 보존 확인 / 실제 브라우저·캡처·시각 검수 미완료.

## 실제 산출물

`prototype/movement/index.html`, `styles.css`, `app.js`, `components.js`, `field.js`, `model.mjs`, `commands.mjs`, `spatial.mjs`, `data/review_data.json`, `assets/world_map_source.png`, `tests/`, `README.md`.

실제 DOM 버튼·텍스트·목록·확인창·SVG 지도 표식/노선과 메모리 상태 모델을 작성했다. 필드는 자체 Canvas 공간 및 픽셀 인물 시연이다. 아트 보드 전체 이미지를 실행 화면으로 사용하지 않았다. 새 정적 생성 이미지는 만들지 않았다.

현행 지침은 `docs/README.md`에서 연결한다. 기존 최상위 문서·원문 52개는 그대로 보존한다. 이전 정책과 변경 기록은 `archive/2026-10-22-ui-policy/`에 별도 보관한다.

## 실행 방법

프로젝트 루트에서:

```powershell
python -B -m http.server 8080 --bind 127.0.0.1 --directory prototype/movement
```

접속: http://127.0.0.1:8080/ . 자세한 조작·검사 명령은 `prototype/movement/README.md`에 있다. 검사에 사용한 서버는 작업 종료 시 중지한다.

## 사용자 확인 대상

정상 브라우저 환경에서 검사를 다시 실행하면 `01-field`, `02-worldmap`, `03-departure-confirm`, `04-journey`, `05-stopped`, `06-stop-field`, `07-arrival`, `08-overload` 캡처를 생성하도록 준비했다. 현재 이 파일들은 존재하지 않는다.

확인할 동선은 월드맵 선택 → 취소 → 재확정 → 명시적 시간 진행 → 정차 현장 → 원래 여정 재개 → 도착이다. 기존 H-2 구조에 새 재질이 맞는지, 버튼 인상·한글 크기·정보량·노선 가독성이 적절한지 검토한다. 현재 검토용 치수·색·시험 지리는 정식 승인값이 아니다.

Map Tool·Godot·Hera·게임패드·실제 저장·3D 물리·다중 파티·경제·전투·채무 종료는 미연동/미검증이다. 현재 보고는 이동 시스템 최종 승인이나 전체 게임 완성을 뜻하지 않는다. 사용자 검토 전 SYS-03으로 진행하지 않는다.
