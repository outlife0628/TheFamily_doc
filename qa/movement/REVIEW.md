# 이동 목업 독립 코드 리뷰 결과

상태: 읽기 전용 독립 리뷰 및 수정 반영. 브라우저 실행 검수와 구분.

리뷰 범위: 현행 명세·지침, HTML/CSS/JS, 상태 모델, 시험 데이터, 단위 검사, 브라우저 검사 스크립트. Git 저장소가 아니므로 새로 추가한 파일을 대상으로 검토했다. 리뷰어는 원본 파일을 변경하지 않았고, 전체 Node 22개 검사의 통과를 독립 확인했다.

| 지적 | 반영 내용 | 확인 범위 |
|---|---|---|
| 같은 우측 슬롯의 연속 클릭이 정차/재개 다음 행동까지 실행 | 공용 `applyTravelAction`에서 다중 클릭 거절 | 모델 상태 대상 회귀 2개 통과. 실제 좌표 더블클릭은 미검수 |
| 근접 Enter가 포커스된 버튼의 동작을 가로챔 | 네이티브 입력 대상은 근접 상호작용에서 제외 | 코드 검토. 실제 키보드 검수 미실행 |
| 평가 코드의 전역 const 중복 선언 | 각 평가를 IIFE로 제한 | 구문/코드 확인. 실제 브라우저 실행 미실행 |
| 검사명보다 좁은 검증 범위 | 합성 조합 이벤트 검사로 명명하고 실제 포인터 입력 경로를 추가 | 미실행인 검사를 통과로 올리지 않음 |
| SVG 요소에 HTMLElement.click 호출, 프로그램 클릭의 포커스 부재 | CDP 실제 포인터 좌표 입력으로 보조 함수 교체 | 코드/구문 확인. 실제 브라우저 미실행 |

필드 좌표는 도시/정차 구역별 보존, 미니맵 콜백은 실제 시연 좌표 전달, 정차는 별도 야외 배경으로 구성했다. 여정의 원본 지도 위 진행 표식 계산은 단위 검사로 확인했다.

판단 보류: 실제 레이아웃·포커스·IME·지도 패닝·아트 적합성은 실행 증거가 없어 미완료다. 확인창 도중 유효 운임 변경은 현재 UI에서 가능한 경로가 없으며, 자금 부족 재검사는 모델 검사로 확인했다. 역방향 정차일의 실제 지리적 의미는 시험 데이터 정의이므로 정식 규칙으로 확정하지 않았다. Godot/Map Tool·게임 저장·게임패드는 현 단계 밖이다.
