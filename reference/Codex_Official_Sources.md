# Codex 설치·작업 지침 참고

**확인일:** 2026-10-22. 아래는 서비스 사용법 참고이며 게임 규칙의 출처가 아니다.

- IDE 설치·프로젝트 열기·사이드바: https://developers.openai.com/codex/ide/ (현재 공식 ChatGPT Learn 문서로 연결)
- ChatGPT 계정 로그인: https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan
- AGENTS.md 탐색과 적용: https://developers.openai.com/codex/guides/agents-md/
- Windows 네이티브/샌드박스: https://developers.openai.com/codex/windows/
- 권한 운영 참고: https://openai.com/index/running-codex-safely/

공식 안내는 VS Code 호환 확장·ChatGPT 로그인·Windows 네이티브 작업과 프로젝트별 AGENTS.md 사용을 설명한다. 실제 화면의 메뉴명·관리자 정책·설치 버전은 사용자의 환경에서 확인한다. AGENTS.md의 읽기 순서를 확인하되 모든 연결된 파일을 자동으로 읽었다고 가정하지 않는다.

이전 대화나 첨부파일이 새 작업 문맥에 자동으로 들어왔다는 전제 대신, 작업에 필요한 문서와 이미지를 프로젝트 폴더에 넣고 실제 읽은 자료를 확인하는 운영을 사용한다.
