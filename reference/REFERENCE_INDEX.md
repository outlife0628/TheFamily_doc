# 자료 색인과 우선순위

## 적용 순서

현재 작업에 대한 사용자의 명시 지시 → `CURRENT_DECISIONS.md`의 해당 결정 → 승인 범위 안의 시스템 원문 → 아직 대체되지 않은 원작의 설정·시나리오 순으로 확인한다. 이미지 아트는 게임 규칙의 원본이 아니다. 최신이라고 적힌 옛 파일 하나가 모든 뒤의 결정을 대체하는 것도 아니다.

이 순서는 프로젝트 내부 문서의 내용 우선순위이며, 도구의 시스템/안전 정책 또는 조직 관리 규칙을 덮어쓰는 지시가 아니다.

## 현재 작업에서 볼 원문

- `design_snapshot/01_Basic_System_UI_Ver0.4.2.md`: 기본 시스템의 승인된 큰 규칙.
- `design_snapshot/02_Movement_System_UI_Ver0.3.md`: 이동 기능·월드맵·상태·예외. 확대 프로필/아트/기존 HTML 상태는 최신 결정으로 교체할 대상.
- `design_snapshot/00_Planning_Map_Ver0.6.md`: 시스템별 책임과 검토 순서. 원문 내 일부 버전/상태 표기는 이전 스냅샷이므로 현재 상태는 최상위 문서를 따른다.
- `design_snapshot/review/Map_Tool_Integration_Checklist.md`: 아직 확인되지 않은 툴 사양 목록.
- `guideline_snapshot/31_UI_Production_Guidelines_Ver0.8.1.md`, `35_UI_Concept_Baseline_Ver0.8.1.md`: 공용 구조와 UX 원문. 현재 글씨/아트 지시를 반영해야 한다.

이 폴더는 원문 보존을 위해 내부 상대 링크를 변조하지 않았다. 옛 HTML·QA·동일 패키지의 주변 파일을 가리키는 원문 링크는 이 인수인계 패키지에서 열리지 않을 수 있다. 옛 링크를 현재 구현물이 존재한다는 근거로 사용하지 않는다.

## 시각 자료

| 폴더/파일 | 용도 |
|---|---|
| `world/world_map_source.png` | 사용자 월드맵 원본. 지형/비율 유지, 동적 표식·노선은 분리 |
| `art/approved_direction/simplified_movement_concept.png` | 장식 축소 후 목업 진행의 기준 아트 방향 |
| `art/style_sources/` | 사용자가 올린 13개 참고 이미지. 재질·색·아이콘 인상 분석용 |
| `art/screen_expansions_review_only/` | 최근 만든 4개 정적 이미지. 실제 구현/최종 승인 자료 아님 |

`approved_direction`은 아트 방향에 대한 명칭이다. 보드 속 Arcadium 계열 지명, 4명 초상·레벨, 3개 퀘스트, 특정 버튼 배치, 임의 수치를 승인한 의미가 아니다. 구조 변경이 아닌 아트 교체라는 사용자 지시를 유지한다.

## 원작

`scenario/`의 12개 파일을 원문 보존했다. 현재 시스템이 덮어쓴 범위와 스토리의 고유 사실을 구분한다. 예를 들어 원문 일부의 '크리스 팀만 직접 조작'이나 '1개월=1턴 가안'을 최신 다중 파티 전환/행동 기반 공통 날짜의 확정 규칙 대신 적용하지 않는다. 첫 브루노 전투의 상세 결과는 최신 Act 2 상세와 원작 최신 변경 기준을 대조한다.

정식 인물명은 크리스·브람 하르트·엘리아나 베일·올리버 크로포드다. 시드리아는 세 종족 공동도시이며 레퍼런스 이미지 속 다른 도시의 세계관을 사용하지 않는다.

## 포함하지 않은 것

폐기 지정된 구형 UI HTML, 그 코드·실행 캡처·QA 성공 기록, 새 HTML/엔진 코드, 비밀키·인증서·계정정보는 포함하지 않았다. 로컬에 보존된 구형 파일이 있더라도 다시 현재 아트 기준으로 사용하거나 승인 없이 삭제하지 않는다.
