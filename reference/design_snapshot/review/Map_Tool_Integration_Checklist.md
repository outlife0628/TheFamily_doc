검토용 HTML에는 실제 Map Tool 어댑터가 연결되어 있지 않다. 도구 명칭이나 과거 기획안만으로 기능 지원을 인정하지 않는다. 도구 제작자에게 이 표를 현재 구현 의무로 지시하는 문서가 아니다.

변경은 ① 기술 바인딩/단위 조정 ② 같은 플레이를 위한 표현 조정 ③ 플레이 규칙 변경을 구분한다. ③은 사용자 재검토를 필수로 한다. 모든 경우 관련 UI 표시·불가 사유·저장·회귀 검사를 함께 갱신한다.

월드맵 그림·도시 마커·노선 그래프는 독립 자료다. Tool이 이들까지 저작/출력한다고 단정하지 않는다. 현재 월드맵 배경 원본은 보존되며 도시 좌표는 검토용이다.
